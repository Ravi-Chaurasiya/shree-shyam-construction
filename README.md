# Shri Shyam Construction

Company website for Shri Shyam Construction, a construction and management consultancy.

## Technology

- React and TypeScript
- TanStack Start and TanStack Router
- Vite and Tailwind CSS

## Development

Install dependencies and start the local development server:

```sh
bun install
bun run dev
```

## Scripts

| Command | Description |
| --- | --- |
| `bun run dev` | Start the development server |
| `bun run build` | Create a production build |
| `bun run preview` | Preview the production build |
| `bun run lint` | Run ESLint |
| `bun test` | Run the test suite |

## Project structure

- `src/routes/` — file-based pages and the root route
- `src/components/` — shared page and UI components
- `src/assets/` — images and other imported assets
- `src/lib/` — shared application utilities
